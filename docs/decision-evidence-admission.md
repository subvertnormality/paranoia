# Arbitration decision evidence admission

Arbitration now states the literal repository-relative citation grammar in the initial prompt and validates declared repository references before accepting each decider vote. DecisionEvidence is the repository-aware boundary; arbitration.py continues to own pure trailer semantics and final substantiation.

The boundary reuses the existing parser and exact pinned-snapshot resolver. An invalid declaration uses the same single correction allowance as a malformed trailer. Both faulty citation fields fit in the bounded diagnostic, even when an offending token is oversized. Absolute paths, missing files, old revisions, inert symlinks and invalid line coordinates are not rewritten into valid evidence.

NONE remains a legal absence of support. A well-formed SOURCE reference does not establish packet membership, authority or entailment. Successful correction does not waive round-two gained-evidence requirements. Final grounding can still return UNRESOLVED. A second invalid reply fails with both attempts retained; an execution failure does not gain another retry.

The experiment targets fewer unresolved tool calls and faster correct convergence. It can spend the existing correction call inside an affected dispatch, so individual call latency may rise. The frozen eight-dispatch baseline/candidate campaign measures outcomes, provider attempts and total elapsed time; no general performance claim is made before those results.

The [frozen contract](decision-evidence-admission-plan.md) owns delivery gates. The separate [native batching experiment](native-snapshot-batching-results.md) remains withheld.
