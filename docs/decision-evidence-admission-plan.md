# Arbitration decision evidence admission

## Frozen scope
Trusted single local operator and OS; repository, plan, provider and fetched bytes are untrusted static data. Ordinary edits invalidate snapshot evidence or block/retry. Reviewers use separate inert workspaces of one pinned snapshot and existing provider/public HTTP boundaries. Hundreds to thousands of files, tens to low hundreds of claims, two concurrent arbitration deciders, evidence useful within minutes. False clear and wrong evidence binding have high impact; recoverable blocking is acceptable. Exclude hostile local races, compromised OS, multi-tenancy, deliberately corrupted state recovery and universal speed guarantees.

## Problem and architectural boundary
The native snapshot batching campaign at /tmp/paranoia-native-batch-live-20260906 completed four dispatches with 16 provider calls. Three remained unresolved because Codex declared absolute temporary-workspace citations; one failure was on unchanged main. Correct rejection occurred only after the decider's existing correction opportunity was gone. Batching stays withheld under its original acceptance gate. This independent card starts from main 33394cb and changes decision admission, not batching or that gate.

## Obligations
A1. Introduce one typed, independently testable decision-evidence admission boundary between trailer parsing and accepting a Cast. Validate declared repository citation syntax without silently dropping malformed tokens, then resolve each declared repository reference with the existing evidence.resolve_citation against the exact pinned snapshot. Preserve the current supported repository/ prefix projection; add no new path aliases, absolute-path rewriting, line clamping, symlink following, historical evidence, or weaker resolution.
A2. A2 is authoritative for semantic and final grounding: preserve NONE as a legal absence of evidence and preserve model-owned authority, entailment and relevance decisions, including negative decisions. SOURCE references retain their existing capture/authority/entailment ownership and final substantiation. This card must not turn lack of support into forced agreement or allow correction to substitute for independent final grounding.
A3. Feed repairable declaration failures through the existing two-attempt decider loop, sharing its single correction allowance with trailer-format errors. Return a bounded diagnostic naming all independently detectable faulty declared fields within that bound and the literal repository-relative path:positive-line grammar. An exhausted retry remains fail-closed with both attempts and every completed sibling retained. Provider execution failures do not gain a retry. No additional review round, provider role, persistence protocol, or provider session contract.
A4. Preserve A1 resolution and A2 grounding, including carried-evidence anti-capitulation. Keep prompt limits, timeout/call admission, raw attempt accounting and workspace cleanup authoritative. Do not introduce a second path-policy implementation or whole-repository cache. Prefer a small typed boundary to another special-case branch in the handler.
A5. Update public documentation and repository instructions before CODE review. After implementation starts, review the code diff against this exact contract; do not reopen plan review as implementation acceptance.
