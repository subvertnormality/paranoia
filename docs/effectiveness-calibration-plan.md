## Frozen operating model
One trusted local operator and OS, with signed-in Codex and Claude CLIs. Repository, plan, provider and fixture bytes are untrusted static data. Reviewers read but never execute repository-selected code. The implementing agent executes only the explicitly authored/extracted public fixtures for calibration and tests, without network or fixture-selected subprocesses. Ordinary edits invalidate review/campaign bindings. Three census lanes may run concurrently; live slots run sequentially. Fixtures have a few files, tens to hundreds of lines, and at most 100 parser claims. Normal review scope remains tens to low hundreds of claims and evidence useful within minutes. Network is the existing provider CLI boundary; no web research or external fact verification is needed in this card. False clear, authority error and incorrect evidence binding have high impact; recoverable blocking and honest inconclusive measurements are acceptable. Exclude hostile local races, compromised OS, multi-tenancy, corrupted-state recovery, formal proof and population guarantees.
